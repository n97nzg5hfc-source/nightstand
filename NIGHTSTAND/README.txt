NIGHTSTAND — FIRST DASHBOARD BUILD

This is the first visual prototype:
- Large digital clock on the left
- Six dashboard widgets with varied sizes
- News and Apple Music preview cards
- Bottom navigation and placeholder pages
- Basic offline caching support

IMPORTANT:
This is a front-end prototype. Weather, live news, Google Calendar, Apple Music, notifications, and dependable alarms are NOT connected yet. We'll integrate those in later stages. iPadOS may restrict battery reporting and background behavior. Use the iPad Clock app as the reliable alarm backup.

NEXT:
1. Upload these files to a static HTTPS host (GitHub Pages is one free option).
2. Open the hosted HTTPS address in Safari on the iPad.
3. Use Share > Add to Home Screen.
4. Open it from the new Home Screen icon.

The first upload/setup can be done from your MacBook. It does not need to remain on afterward.
